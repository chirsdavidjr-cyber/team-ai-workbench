# 交接说明（给别的 AI 配置本 skill 用）

这份文件回答一个问题：**要把什么交给别的 AI，它才能按顺序把这个采集 skill 配好并跑起来。**

## 一句话

把这个交接包文件夹整体交给对方，让它**先读 `SKILL.md`**。SKILL.md 是入口，会指到其余所有文件。不要只给某一两个脚本——少了规则文档，对方会不知道边界和台账要求。

## 交接包清单

本交接包共 16 个文件，分四层。按下面的顺序读：

### 第一层：入口（必读）

| 文件 | 作用 |
| --- | --- |
| `SKILL.md` | 主入口。定位、范围边界、默认场景、工作流、交付物、合规、审视要点。读完这份就知道要干什么 |

### 第二层：规则（配置前必读）

| 文件 | 作用 |
| --- | --- |
| `references/compliance.md` | 合规硬规则：不登录、不绕验证码、不采隐私字段、脱敏规则、受阻即停 |
| `references/default-scope.md` | 默认采集场景：五大方向、站点、关键词映射、执行规则 |
| `references/keyword-bank.md` | 关键词库（六节全内联）+ 第七节排除词（本公司品牌词的处理规则） |

### 第三层：执行规范（跑之前读）

| 文件 | 作用 |
| --- | --- |
| `references/site-registry.md` | 站点台账：实测过的站点、栏目 URL、抓取方式；明确排除本公司官网与舆情站点 |
| `references/ledger-spec.md` | 台账规范：三层台账、字段、配方六段、追溯链 |
| `references/delivery.md` | 交付规范：目录结构、条目结构、原文格式、收工回报 |
| `references/general-request.md` | 通用需求处理：其他采集需求如何映射站点与关键词 |

### 第四层：脚本与配置（执行时用）

| 文件 | 作用 |
| --- | --- |
| `scripts/collect.py` | 落盘：脱敏、去重、原文存档、汇总 CSV、manifest |
| `scripts/ledger.py` | 台账生成：明细台账、总台账、配方、当前区 |
| `scripts/fetch_public.js` | 通用公开页抓取：JS 渲染页/翻页时用，本机 Chrome + playwright-core |
| `templates/config.default.json` | 默认场景配置：站点、方向、限速、排除项 |
| `templates/ledger_template.csv` | 台账表头模板 |

### 审视用（对方要审视时给）

| 文件 | 作用 |
| --- | --- |
| `审视记录.md` | 交付前自检实证：站点实测、端到端、脱敏、安全审计结果 |
| `references/review-checklist.md` | 审视清单：十节核对项，审视者填核对结论 |

## 给别的 AI 的配置指令模板

可以直接把下面这段话连同整个目录一起发过去：

```
这是一个公开网页采集 skill。按以下顺序配置：

1. 读 SKILL.md，理解定位、范围边界、工作流。
2. 读 references/compliance.md，确认合规规则（不登录、不绕验证码、不采隐私、脱敏、受阻即停）。
3. 读 references/default-scope.md 与 references/keyword-bank.md，确认默认场景五大方向与关键词。
4. 读 references/site-registry.md，确认站点台账；新站点先实测再登记。
5. 读 references/ledger-spec.md 与 references/delivery.md，确认台账与交付格式。
6. 检查运行环境：Python 3（collect.py/ledger.py 纯标准库）；需要抓 JS 渲染页时再要 Node + playwright-core + 本机 Chrome。
7. 先跑一次最小验证：用中国保险行业协会站点抓几条，调 collect.py 落盘，再调 ledger.py 生成台账，确认 CSV 可读、台账字段齐全。
8. 若要审视，按 references/review-checklist.md 十节逐项核对，发现问题直接改文件。

边界（不可变）：不采本公司（太平洋产险/太保）自有网页；不纳入舆情监测（黑猫投诉等）；只做无需登录的公开网页。
```

## 三条硬边界（配置时务必转达）

1. **不采本公司自有网页**。服务对象就是太平洋产险，自己家的官网采了没有情报价值。关键词库第七节是排除词规则：从本公司域名采的整条丢弃；但外部站点提到太保的（如监管处罚、行业对比）是要的情报，保留。
2. **不纳入舆情监测**。黑猫投诉这类投诉平台属舆情监测范畴，不是"行业最新信息"，不在默认场景。另起 skill 或另配场景。
3. **只做公开网页**。不登录、不代扫码、不碰用户已登录态、不绕验证码、不采隐私字段、不对外发送。

## 环境依赖（最小化）

- **必需**：Python 3（3.10+，`collect.py` 与 `ledger.py` 只用标准库）。
- **可选**：Node.js + playwright-core + 本机 Chrome，仅当遇到 JS 渲染或需翻页的站点时才用 `fetch_public.js`。已实测的本机环境：Chrome 在 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`，playwright-core 在隔离 workspace 的 node_modules。
- **无需**：不需要装 agent-browser，不需要下载 Chromium，不需要任何账号登录。

## 验证是否配好

对方跑通下面这条链就算配好：

1. 用中国保险行业协会 `https://www.iachina.cn/` 抓几条公开条目，存成 JSONL（字段见 `delivery.md` 的标准条目结构）。
2. 跑 `collect.py`，产出批次目录，含 items.jsonl / summary.csv / manifest.json / 原文存档。
3. 跑 `ledger.py`，产出明细台账.csv / 配方.md / 采集总台账.csv / 当前区 latest.csv。
4. 打开 summary.csv 确认 Excel 可读、无乱码；抽一条确认链接可回指、正文完整。
5. 确认脱敏生效：造一条含手机号/身份证/住址/订单号的样例，落盘后这些字段应变成 `[类型已脱敏]`。

## 常见配置问题

- **问：能不能只给脚本，不给规则文档？**
  答：不行。脚本只管落盘和台账，合规边界、默认场景、关键词、站点都在规则文档里。少了它们，对方采什么、怎么算合规、台账怎么填都没有依据。

- **问：别的 AI 不是 WorkBuddy，没有 skill 机制怎么办？**
  答：这些就是普通 Markdown 和 Python/JS 文件，把目录拷过去，让它读文件、按流程执行即可。不依赖任何平台机制。

- **问：要不要给它看实测记录？**
  答：要。`审视记录.md` 里有站点实测、端到端、脱敏、安全审计的实证，能省掉对方重复验证的时间。
