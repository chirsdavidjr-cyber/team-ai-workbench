# 合规规则（自包含）

本文件是采集行为的硬约束，任何动作先过这一页。不通过就不做，不请示、不变通。

## 允许范围

- 只采**无需登录**即可访问的公开页面：政府/监管官网、行业协会官网、企业官网公开栏目、公开新闻与公告页。
- 可采字段：页面公开标题、正文全文、公开发布时间、来源机构、原文链接、作者公开署名（如有）、页面公开标注的文号/栏目名。
- 全站默认限速：每条间隔 ≥2 秒，单站单批 ≤200 条；用户明确要求更保守时按其要求。

## 硬性禁止

- 不登录：不代填账号密码、不代扫码、不读取用户浏览器已登录的 cookie/localStorage、不使用用户私有 profile。
- 不绕过：验证码、滑块、短信验证、人机验证、登录墙、IP 风控、设备指纹校验。遇到即停，记录受阻原因。
- 不伪造：x-s、x-t、a_bogus、x-bogus、msToken、verifyFp、_signature、sign、token 等签名参数，一律不分析不复现。
- 不批量注册、不模拟多账号、不换 IP 续采。
- 不采隐私字段：手机号、身份证号、住址、真实姓名、私信内容、非公开群聊、好友关系、订单号、保单号、客户编号、银行卡号。页面上能看到也不采。
- 不改 robots.txt 或服务条款判断去迁就采集目标；站点明确禁止采集就不采。
- 不对外发送：不上传、不发邮件、不发群、不调外部 API 转发。结果只落本机。

## 脱敏规则（落盘前执行）

即使正文里出现以下内容，也要处理后再落盘：

| 类型 | 处理 |
| --- | --- |
| 手机号 / 固话 | 删除或打码，只留区号级别 |
| 身份证号 / 统一社会信用代码中的个人段 | 删除 |
| 详细住址 / 门牌号 | 只留到城市或区县 |
| 姓名（非机构公开署名） | 删除，机构发言人姓名可留 |
| 订单号 / 保单号 / 客户编号 | 删除 |
| 银行账号 | 删除 |
| 投诉人平台昵称（如"洞察喵"） | 可留，属平台公开匿名昵称 |

脱敏在 `scripts/collect.py` 内正则处理，处理后在 manifest 记录"已脱敏"。

## 受阻处理

遇到以下情况立即停止该站点，写入 hindered 字段，不重试、不换号、不绕：

- 登录墙、验证码、滑块、账号异常提示
- 页面返回空正文或反复跳转
- 请求被限流
- 正文出现大量隐私字段（说明选择器或字段设计有问题，先修再采）

## 用途边界

采集结果用于公开信息研究、行业与竞品观察、监管政策跟踪。不得用于定向个人营销、个人信息画像或任何需个人授权的场景。

## 站点清单的合规前提

`references/site-registry.md` 里所有站点都是实测过**不登录可见**的公开页面。新增站点必须先实测确认无需登录，才能登记。需要登录的站点一律不进台账。
