## 四、明确排除的站点类型

- **舆情监测类**：黑猫投诉（tousu.sina.com.cn）等投诉平台。属舆情监测范畴，不是"行业最新信息"，暂不纳入本 skill 默认场景。后续若做舆情监测，另起 skill 或另配场景。
- **本公司自有网页**：见上节。

## 五、需要浏览器渲染但仍公开的场景

以下场景 WebFetch 拿不到正文，需 `scripts/fetch_public.js` 用本机 Chrome 渲染；仍属公开，不涉及登录：

- 列表由 JavaScript 动态加载的页面
- 需要点击"加载更多"翻页的页面
- 小红书公开推荐流（探索页，实测无需登录可见标题/作者/点赞，但关键词搜索需登录，不在本 skill 范围）

## 六、新站点登记流程（不含本公司与舆情站点）

1. 用 WebFetch 访问候选站点，确认无需登录可见内容。
2. 记录：站点名、入口 URL、可达性、重点栏目 URL、抓取方式、字段、合规注意。
3. 加入上表对应分类，标明实测日期。
4. 未实测的站点标注"先探测"，不要当作已验证。
