# 团队 AI 工作台

面向 10 人小团队 AI 工作平台。产品方案见根目录《PRD-团队AI工作台.html》。

## 快速开始

```bash
./dev.sh    # 启动前后端（首次运行自动安装依赖）
./stop.sh   # 停止服务
```

- 前端：http://localhost:3000
- 后端 API：http://127.0.0.1:8000/docs（交互式接口文档）
- 管理员账号在 `backend/.env` 初始化（默认 admin@team.local / admin123456，请修改后重启）

## 目录结构

```
backend/   FastAPI 后端（SQLite 存储，Step 9 迁移 Postgres）
frontend/  Next.js 前端
logs/      dev.sh 产生的运行日志
```

## 开发路线（逐步闭环）

| Step | 内容 | 状态 |
|---|---|---|
| 1 | 骨架 + 认证 + 主布局 | ✅ |
| 2 | 对话闭环（多模型/流式/会话/附件解析/agent 工具调用） | ✅ |
| 3 | 知识库闭环（上传/检索/引用/四区骨架/AI 归类/图谱） | ✅ |
| 4 | 问数闭环（Excel/画像/语义层/Text2SQL + **全局问数**：目录选表 → 多表 JOIN → 解读） | ✅ |
| 5 | 工具卡（agent/skill/template）+ 沉淀 | ✅ |
| 6 | 审核流（知识库/数据集申请入团队库，管理员双区审核） | ✅ |
| 7 | 批量任务中心（进度/结果/CSV 导出，可对话内发起） | ✅ |
| 8 | 我的工作台（多工作台/自定义布局/默认卡） | ✅ 基础版（余关注动态订阅） |
| 9 | 部署闭环（Docker 化 ✅ 局域网上线；Postgres 迁移待做） | 🔶 |

> 开发明细与每轮验收记录见根目录《开发记录.md》（截至第 19 轮：全局问数 · Trae 式两段式）。
